# OE8CTK Website – Adding a New Project

This guide explains how to add a new project to the OE8CTK main page and project grid.
It includes ready-to-copy code snippets for slider, grid, filter, and lightbox.

---

## 1️⃣ Prepare Images

* Place all project images in the `images/` folder.
* Use descriptive filenames, for example:

```
images/myproject1.jpg
images/myproject2.jpg
```

* Images will be used in the **project grid**, **slider**, and **project page gallery**.

---

## 2️⃣ Create a New Project Page

1. Copy `projects/template_project.html` and rename it, e.g.:

```
projects/my_new_project.html
```

2. Update the file:

   * `<title>` → Project name
   * `<h1>` → Project name
   * `<section>` blocks → Describe each step
   * `.gallery` → Add step images

**Example:**

```
<section>
  <h2>Step 1: Antenna Build</h2>
  <p>Description of the first step.</p>
  <div class="gallery">
    <img src="../images/myproject1.jpg" alt="Step 1">
    <img src="../images/myproject2.jpg" alt="Step 1 Detail">
  </div>
</section>
```

> Copy `<section>` blocks for additional steps.

---

## 3️⃣ Add Project to `projects.js`

1. Open `projects.js`.
2. Add a new object at the end of the array:

```
{
  title: "My New Project",
  image: "images/myproject1.jpg",       // Thumbnail for grid & slider
  link: "projects/my_new_project.html", // Project page
  tags: ["transceiver","portable"],     // Filter tags
  description: "Short description for grid & slider."
}
```

**Explanation:**

* `title` → Displayed in grid, slider, overlay
* `image` → Thumbnail
* `link` → Path to project page
* `tags` → Must match dropdown filter options
* `description` → Shown in overlay & slider

---

## 4️⃣ Update Filter Dropdown (Optional)

* If your project has new tags, update `<select>` in `index.html`:

```
<select onchange="filterProjects(this.value)">
  <option value="all">All Projects</option>
  <option value="transceiver">Transceivers</option>
  <option value="antenna">Antennas</option>
  <option value="newtag">New Tag Name</option> <!-- Add new tag here -->
</select>
```

---

## 5️⃣ Project Grid & Overlay

* The grid and overlay are automatically generated from `projects.js`.
* Example structure (generated by `filter.js`):

```
<a href="projects/my_new_project.html">
  <div class="card" data-tags="transceiver portable">
    <img src="images/myproject1.jpg" alt="My New Project">
    <div class="title">My New Project</div>
    <div class="overlay">
      <h3>My New Project</h3>
      <p>Short description for grid & slider.</p>
    </div>
  </div>
</a>
```

> Do **not** manually copy this for every project; it’s generated automatically.

---

## 6️⃣ Slider (Optional)

* The slider shows the first 3 projects in `projects.js`.
* To include your project, update `slider.js`:

```
projects.slice(0,4).forEach(p => { // Increase slice if needed
  slider.innerHTML += `
    <div class="slide">
      <img src="${p.image}">
      <div class="caption">
        <h3>${p.title}</h3>
        <p>${p.description}</p>
      </div>
    </div>
  `;
});
```

---

## 7️⃣ Lightbox Gallery

* All images inside `.gallery` on the project page are automatically clickable.
* Example:

```
<div class="gallery">
  <img src="../images/myproject1.jpg" alt="Step 1">
  <img src="../images/myproject2.jpg" alt="Step 2">
</div>
```

* Include `gallery.js` at the end of the project page:

```
<script src="../gallery.js"></script>
```

---

## 8️⃣ Upload & Verify

1. Save all files.
2. Upload `index.html`, `projects.js`, `slider.js`, `filter.js`, `gallery.js`, `style.css`, and `images/` to your server.
3. Verify:

   * New project appears in the **grid**
   * Filter dropdown works
   * Slider shows new project (if configured)
   * Lightbox works on project page

---

## ✅ Tips for Future Projects

1. Always add **images first**.
2. Copy `template_project.html` for new projects.
3. Only update `projects.js` – grid, slider, and filter auto-update.
4. Add new tags in dropdown only once.
5. Use `.gallery` for all step images – Lightbox works automatically.
